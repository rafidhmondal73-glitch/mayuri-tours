Mayuri Tours & Travel — GitHub Pages Demo
This is a standalone static version of the Mayuri Tours & Travel demo website.
It does NOT use:
Google Apps Script
Google Drive
Code.gs
Logo.html
The Mayuri logo is embedded directly in `index.html`.
Publish on GitHub Pages
Create a GitHub account if you do not already have one.
Create a new repository, for example: `mayuri-tours`.
Upload `index.html`.
Open the repository's Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Select the `main` branch and `/ (root)`.
Save.
GitHub will provide a URL similar to:
`https://YOURUSERNAME.github.io/mayuri-tours/`
All major buttons are intentionally demo-only and open the demo notice.
